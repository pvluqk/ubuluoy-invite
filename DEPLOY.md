# Как выложить сайт и дать ссылки

Сейчас сайт работает только у тебя на компьютере (`127.0.0.1`).  
Чтобы другие открыли с телефона — нужен хостинг. Свой красивый домен — потом, за 5 минут.

## Две ссылки (запомни)

После выкладки будет так:

1. **Приглашение (всем гостям):**  
   `https://ТВОЙ-АДРЕС/`

2. **Кто записался (только организаторам):**  
   `https://ТВОЙ-АДРЕС/guests?key=ubuluoy-secret-2026`  
   Ключ можно сменить в `.env` → `ADMIN_KEY`.

---

## Вариант A — Render (бесплатно, рекомендую)

1. Зарегистрируйся на [render.com](https://render.com) (через Google удобно).
2. На компьютере поставь **Git** (если ещё нет): [git-scm.com](https://git-scm.com/download/win)  
   или скажи мне — поставлю с твоего ОК.
3. Залей проект на GitHub (я помогу командами после установки Git).
4. В Render: **New → Blueprint** → выбери репозиторий (есть файл `render.yaml`).
5. Через 1–2 минуты получишь адрес вида:  
   `https://ubuluoy-invite.onrender.com`
6. Эту ссылку отправляй на правки. Ссылку гостей — только своим.

Бесплатный Render «засыпает» после простоя ~15 мин — первый заход может ждать 30–60 сек. Для правок это нормально.

---

## Вариант B — свой домен (когда будете готовы)

Пример: `https://ubuluoy.ru` или `https://приглашение.твой-домен.ru`

1. Купи домен (Reg.ru, Timeweb, Beget, Cloudflare).
2. В Render → твой сервис → **Settings → Custom Domains** → добавь домен.
3. В панели домена пропиши DNS, как покажет Render (обычно CNAME).
4. Подожди 5–30 минут — HTTPS включится сам.

---

## Пока без выкладки (только Wi‑Fi дома)

1. Запусти `start.bat`
2. В окне будет IP вида `http://192.168.x.x:8000`
3. Другие в **той же Wi‑Fi** откроют эту ссылку  
   (из интернета с другой сети — **не** откроется)

---

Когда скажешь «ставим Git» или «есть аккаунт Render/GitHub» — выложим вместе до рабочей ссылки.
